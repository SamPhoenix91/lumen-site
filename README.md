# lumen-site

The website for Lumen, a media player for Plex, Jellyfin, Emby and IPTV on Apple TV, iPhone and iPad.

Served by GitHub Pages at https://lumen.nemul.dev. Plain HTML and CSS, no build step.

- `index.html`: home page
- `privacy/`: privacy policy
- `screenshots/`: drop images in this folder and add a `<figure>` for each to `screenshots/index.html`
